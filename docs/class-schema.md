# Схема классов и бизнес-процессов

## Основные сущности

- [User](#user)
- [Executor](#executor)
- [Category](#category)
- [Task](#task)
- [Attachment](#attachment)
- [Bid](#bid)
- [Review](#review)
- [City](#city)

### User

Зарегистрированный пользователь. Все пользователи могут создавать Задания, выступая в роли Заказчика (customer).

### Executor

Профиль Пользователя, позволяющий откликаться на Задания в роли Исполнителя (executor).

### Category

Категория задания.

### Task

Задание.

### Attachment

Файлы (Задания). Задание не обязано содержать прикреплённые файлы. Загруженные файлы могут быть любого формата.

### Bid

Предложения/ставки Исполнителя на выполнение Задания.

### Review

Отзывы Заказчика о работе Исполнителя (по итогу выполнения конкретного Задания).

### City

Справочник Городов используется при регистрации пользователя и создании Задания
